For a law mu on the line, symmetric with a finite second moment sigma2 = E X^2, reals c > -1 and C >= 1, and a profile q, let

V_c(q) = 2 E[X q(X)] - E[q(X)^2] - c (E q(X))^2.

A profile is admissible for C when it is measurable with t <= q <= C t for some t >= 0, and admissible almost everywhere when these bounds hold mu-almost everywhere. For a real a and t >= 0, the clipped profile

q_{a,t}(x) = min (max (x - a) t) (C t)

is admissible; with l = t + a and u = C t + a it is t + (x - l)_+ - (x - u)_+, and q_{a,t}(x) is the point of [t, C t] closest to x - a. m and s are the upper moments of variational.v.

Main results:

  • clip_first_order: under the balance m(-l) = C m(u), the residual w(x) = x - a - q_{a,t}(x) has E[w (q - q_{a,t})] <= 0 for every admissible q; clip_residual_profile: E[w q_{a,t}] = 0.
  • clip_optimal: if moreover a = c E q_{a,t} (a fixed point), q_{a,t} maximizes V_c over the admissible profiles. clip_objective_profile: V_c(q_{a,t}) = E[X q_{a,t}(X)]; clip_objective_radial: V_c(q_{a,t}) = E[q_{a,t}(X)^2] + c (E q_{a,t}(X))^2; clip_objectiveE: V_c(q_{a,t}) = J(l) - J(u), with J(w) = s(w) + w m(w).
  • clip_energy_shiftE: s(-t - a) + s(C t + a) = E (X - a - q_{a,t}(X))^2, the mean squared distance from X - a to [t, C t].
  • The dual form, with clip_dual mu c C b the function D(b) = sigma2 + c (1 + c) b^2 - inf_(t' >= 0) (s(-t' - c b) + s(C t' + c b)), under the balance and the fixed point: clip_dual_opt: D(E q_{a,t}) = V_c(q_{a,t}); clip_dual_le: D(b) <= V_c(q_{a,t}) for every b if c <= 0; clip_dual_ge: V_c(q_{a,t}) <= D(b) for every b if c >= 0; clip_dual_window: 0 <= E q_{a,t} and min(1, 1 + c)^2 (E q_{a,t})^2 <= sigma2.
  • clip_objective_add: for bounded measurable q and h, V_c(q + h) is V_c(q) + 2 E[(X - c E q(X) - q(X)) h(X)] - E[h(X)^2] - c (E h(X))^2; clip_admissible_le: a profile admissible for C is admissible for every C' >= C.
  • For every law mu and all reals c and C: two measurable profiles equal almost everywhere have the same objective (clip_objective_ae_eq). If t <= q <= C t mu-almost everywhere, the clipped profile min(max(q, t), C t) is admissible for C (clip_ae_admissible), equals q almost everywhere (clip_ae_eq) and has the objective of q (clip_ae_objective). So V_c takes the same values on the two classes (clip_objective_ae_set) and has the same supremum on them (clip_value_ae). clip_admissible_ae_integrable: if mu has a finite second moment, the three integrands of V_c are integrable on the almost-everywhere class.
  • Tools: clip_profile_mean, E q_{a,t} = t + m(l) - m(u); clip_energy_shift_min, t minimizes t' |-> s(-t' - a) + s(C t' + a); clip_dual_profile, clip_dual_lower; clip_res_sqE, the expansion of E (X - a - f(X))^2 for a bounded measurable f; the integrability of bounded measurable functions and of their products with x.
