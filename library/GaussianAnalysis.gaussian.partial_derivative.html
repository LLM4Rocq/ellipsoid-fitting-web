A function F : 'rV[R]_n -> R whose partial derivatives 'D_(delta_mx 0 j) F exist everywhere and are continuous is differentiable, and its differential is v |-> \sum_j v 0 j * 'D_(delta_mx 0 j) F x (differentiable_partials, diff_partials). The proof writes the increment of F as a sum of increments along the coordinates and applies the mean value theorem to each (mean_value_coord, partials_expansion).

rV_prefix k hthe row vector h with its coordinates of index k or more set to 0
