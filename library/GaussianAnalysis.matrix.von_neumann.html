For a real symmetric matrix A of size n, spec A is the row vector of its eigenvalues in decreasing order, obtained by sorting the diagonal of the spectral decomposition of real_spectral.v (sym_spectral_diag). This file is part of item G7 of phase 5 (the semicircle law, random_matrix/wigner.v): the Hoffman-Wielandt inequality makes the linear statistics of eigenvalues Lipschitz functions of the matrix, so that Gaussian concentration applies to them, and von Neumann's inequality is used in Lemma 5.14 of Koehler and Sohn (arXiv 2608.27372, line 5909).

Main results:

  • spec_decr, spec_perm, sum_spec, spec_decomposition: spec A is decreasing and is a permutation of sym_spectral_diag A, so \sum_i f (spec A 0 i) does not depend on the decomposition; A = P^T diag_mx (spec A) P for some orthogonal P when A is symmetric.
  • abel_ge0, abel_ge0_sum0: Abel summation, sum_i a_i w_i >= 0 for a decreasing (and nonnegative, or with sum_i w_i = 0) and w with nonnegative partial sums; sum_weight_le: for b decreasing and weights 0 <= c_j <= 1 of total k, sum_j b_j c_j is at most the sum of the k largest b_j.
  • doubly_stochastic_le, doubly_stochastic_le_mx: for a and b decreasing and M doubly stochastic, sum_(i, j) a_i b_j M_ij <= sum_i a_i b_i (without Birkhoff's theorem); orthogonal_sqr_row, orthogonal_sqr_col: the squared entries of an orthogonal matrix form a doubly stochastic matrix.
  • von_neumann_trace: \tr (A B) <= sum_i spec A 0 i * spec B 0 i for A and B symmetric.
  • mxdot_spec: |A|_F^2 = sum_i spec A 0 i ^+ 2; hoffman_wielandt: sum_i (spec A 0 i - spec B 0 i)^2 <= |A - B|_F^2 for A and B symmetric; spec_lipschitz: each eigenvalue is 1-Lipschitz for the Frobenius norm; spec_stat_lipschitz: for f L-Lipschitz, A |-> sum_i f (spec A 0 i) is (L sqrt n)-Lipschitz for the Frobenius norm on symmetric matrices.
