  • trunc_le_forced: if M <= c^k, then min(M kill k S, 1) <= c b / n, with b the number of forced variables of S, since the killing probability is at most (b / (2 n))^k <= (b / n)^k (kfrac_le_pow).
  • sat_capped_varE: sat_capped_var R n k, the variance of the statistic of the statement, is life_var k (sat_cap k n) of the set of all assignments (sat_prefix_lenE of Model.v).
  • sat_variance_bound_explicit: for K >= 3 and N >= K + 1, sat_capped_var R N K <= C N^(1 + 2/K), with C = 8 4^(K+1) K (3 K + 2^(K+2)); sat_variance_bound is its existential form, the form of the statement. The proof takes a = N^(1/K), the block g = floor(2 K a) + 1 <= 3 K a and c = 4 a, so that the cap M = 2^(K+1) N is at most c^K; life_var_le_occ of Pivotal.v, trunc_le_forced, forced_frac_head and integrated_head_forcing of Forcing.v then bound the variance by 2 M c (g M p + (M + 1) M p a^-(K-1)), with p = K / N, and N a^-(K-1) = a, N a^2 = N^(1 + 2/K).

The statement and the manuscript bound Var(V_n) by C n^(1 + 2/k); the Lean theorem bounds the variance of the lifetime by a constant times n (n^(1/k))^2, with a block of size ceil(2 k n^(1/k)). The constant here is explicit (sat_variance_bound_explicit) and holds for every n >= k + 1.
