Let x have law gauss n and y have law gauss m. For A : 'M[R]_(n, k.+1), x *m A is a centered Gaussian vector of covariance A^T *m A, and every centered Gaussian vector of 'rV[R]_k.+1 has this form. If every increment of x *m A has a variance at most that of the same increment of y *m B, that is incr_var A j l <= incr_var B j l for all j and l, then E[rmax (x *m A)] <= E[rmax (y *m B)], where rmax z is the largest coordinate of z (sudakov_fernique). Equal variances and larger covariances imply the hypothesis (slepian).

The proof applies Kahane's comparison inequality (gauss_comparison) to the log-sum-exp function lse b. For every square matrix M, the pairing of M with the Hessian of lse b at z is b / 2 * \sum_(j, l) p_j p_l (M j j + M l l - 2 M j l), with p = softmax b z (lse_hessian). For M = A^T *m A - B^T *m B it is nonpositive. Since rmax z <= lse b z <= rmax z + ln (k + 1) / b, letting b grow concludes.

rmax zthe largest coordinate of the row vector z
lse b zb^-1 * ln (\sum_j expR (b * z 0 j))
softmax b z jexpR (b * z 0 j) / \sum_i expR (b * z 0 i)
incr_var A j l(A^T *m A) j j + (A^T *m A) l l - 2 * (A^T *m A) j l, the variance of (x *m A) 0 j - (x *m A) 0 l

Main results

ResultsStatement
sudakov_fernique
Sudakov-Fernique inequality: for x of law gauss n and y of law gauss m, if each increment (x A)_j - (x A)_l has variance at most that of (y B)_j - (y B)_l, then E[max_j (x A)_j] <= E[max_j (y B)_j].
slepian
Slepian's inequality for expected maxima: if x A and y B have the same variances and each covariance of x A is at least that of y B, then E[max_j (x A)_j] <= E[max_j (y B)_j].
rmax_le_lselse_le_rmaxlse_hessian
The log-sum-exp function lse b z = ln (\sum_j expR (b z_j)) / b, b > 0, satisfies max_j z_j <= lse b z <= max_j z_j + ln (k + 1) / b. Its Hessian paired with a matrix M is b / 2 \sum_(j, l) p_j p_l (M_jj + M_ll - 2 M_jl), with p the softmax weights.
