Every real symmetric matrix A is orthogonally diagonalizable: A = P^T *m diag_mx d *m P with P orthogonal (symmetric_spectral). The proof is the analytic one and works over any realType: the quadratic form of A attains its maximum on the compact unit sphere, a maximizer is an eigenvector, and the Householder reflection that sends it to the first basis vector splits off one dimension. No complex number is used.

The Frobenius norm is compared with mx_norm, the norm of MathComp-Analysis on matrices (the largest absolute value of an entry): mx_norm A <= frobenius A <= sqrt (m n) mx_norm A (mx_norm_le_frobenius, frobenius_le_mx_norm). So the topology of 'M[R]_(m, n) is the topology of the Frobenius norm, and the unit sphere is compact (compact_unit_sphere).

householder wthe Householder reflection 1 - (2 / mxdot w w) *: (w *m w^T) of w : 'cV[R]_n, equal to 1 when w = 0
sym_spectralmx Aan orthogonal matrix P such that A = P^T *m diag_mx (sym_spectral_diag A) *m P when A is symmetric
sym_spectral_diag Athe eigenvalues of A, in the order of the rows of sym_spectralmx A

lemma spectral_trace main result source, line 362 
forall [R : realType] [n : nat] [A P : 'M_n] [d : 'rV_n],
P \is orthogonalmx -> A = P^T *m diag_mx d *m P -> \tr A = \sum_i d 0 i
Main result, as the README states it

If A = P^T diag(d) P with P orthogonal: the trace is the sum of the d_i, the squared Frobenius norm is the sum of the d_i^2, x^T A x = sum_i d_i (P x)_i^2, and x^T A x <= b x^T x for all x if and only if every d_i <= b (likewise for lower bounds, positive semidefiniteness and absolute values).
