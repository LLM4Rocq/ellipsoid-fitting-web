Norms of random vectors and matrices with subgaussian coordinates

Independent coordinates are functions f_i (x_i) of the coordinates of a tuple x of law tuple_prod mu n (lindeberg.v), subgaussian with a common constant K (subgaussian.v). The results are Theorems 3.1.1 and 4.4.5 of Vershynin, High-Dimensional Probability, with explicit constants.

Main results:

  • subgaussian_unit_ge1: a subgaussian constant K of a variable X with E X^2 = 1 is at least 1;
  • norm_concentration: if E f_i (x_i)^2 = 1 for every i, the Euclidean norm |x| = (\sum_i f_i (x_i)^2)^(1/2) satisfies, for t >= 0,
    P(| |x| - sqrt n | >= t) <= 2 exp (- t^2 / (576 K^4)),

    from Bernstein's inequality (bernstein_sum) for the centered subexponential variables f_i (x_i)^2 - 1; the f_i need not be centered;

  • mgf_tail: P(|X| >= r) <= 2 exp (- r^2 / (4 s^2)) for r >= 0 when E exp (l X) <= exp (s^2 l^2) for every real l;
  • opnorm_tail_mgf: for a random m x n matrix A with measurable entries whose bilinear forms u^T A v, |u|, |v| <= 1, satisfy E exp (l u^T A v) <= exp (s^2 l^2) for every real l, and t >= 0,
    P(opnorm A > 12 s (sqrt m + sqrt n + t)) <= 2 exp (- t^2),

    by 1/4-nets of the unit balls (unit_ball_net and opnorm_net_bilinear of nets.v) and the union bound;

  • subgaussian_opnorm_tail: for the m x n matrix A = vec_mx (f_k (x_k))_k of independent centered entries, subgaussian with constant K, and t >= 0,
    P(opnorm A > 21 K (sqrt m + sqrt n + t)) <= 2 exp (- t^2),

    from Hoeffding's inequality (subgaussian_sum_mgf) with s = sqrt 3 K.
