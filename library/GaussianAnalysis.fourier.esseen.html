The Levy concentration function Q(mu, L) = sup_a mu [a, a + L] of a law mu on the real line (conc_fun) is at most one, nondecreasing in L, satisfies Q(mu, L) <= (L / L' + 1) Q(mu, L') (conc_fun_cover), and does not increase when an independent variable is added (conc_fun_add).

Esseen's inequality bounds it by the characteristic function:

Q(mu, 2 pi / T) <= pi^2 / (4 T) \int_{-T}^T |cf mu t| dt    (esseen)
                 = pi^2 / (2 T) \int_0^T |cf mu t| dt       (esseen0),

through the Fejer kernel 2 \int_0^T (1 - t / T) cos (t z) dt = 2 (1 - cos (T z)) / (T z^2) (fejerE), which is at least 4 T / pi^2 for |z| <= pi / T by Jordan's inequality (jordan_sin, jordan_cos).

For independent X_1, ..., X_n of laws mu_k with E[X_k^2] <= v and Q(mu_k, lambda) <= 1 - eps, the law of S = X_1 + ... + X_n satisfies

Q(S, L) <= 2 pi^2 sqrt pi (L + sqrt (v / eps)) / (lambda sqrt (eps n))

(conc_fun_sum). The proof goes through the symmetrization X - X', for which P(|X - X'| < lambda / 2) <= Q(mu, lambda) (sym_small_ball) and 1 - |cf mu t|^2 >= lambda^2 eps t^2 / (4 pi^2) for small |t| (sym_cf_bound).

Laws on the line are probabilities on measurableTypeR R, as in charfun.v.
