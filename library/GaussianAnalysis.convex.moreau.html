Lemma 5.1 of Koehler and Sohn (arXiv 2608.27372, lines 4894-4921; Bauschke and Combettes, section 6.3) in 'rV[R]_N with the Frobenius inner product <x, y> = mxdot x y and |x|^2 = mxdot x x. K is a nonempty closed convex set and C a nonempty closed convex cone: x + t (y - x) is in K for x, y in K and 0 <= t <= 1, and a y is in C for y in C and a >= 0.

proj K zthe nearest point of K to z, if it exists (xget)
polar Cthe polar cone [set u | <u, y> <= 0 for every y in C]
  • proj_exists: a nonempty closed set has a nearest point to every z.
  • proj_variational: p in K is nearest to z iff <z - p, y - p> <= 0 for every y in K; the nearest point is unique (proj_unique), and projP gives K (proj K z) and the variational inequality.
  • proj_nonexpansive: |proj K z - proj K z'| <= |z - z'|.
  • cone_projP: p = proj C z iff p is in C, z - p is in polar C and <z - p, p> = 0.
  • moreau, Lemma 5.1: z = proj C z + proj (polar C) z with <proj C z, proj (polar C) z> = 0, hence (moreau_norm) |z|^2 = |proj C z|^2 + |proj (polar C) z|^2.
  • cone_proj_support, (eq:cone-projection-support): sup_(y in C, |y| <= 1) <z, y> = |proj C z|.
