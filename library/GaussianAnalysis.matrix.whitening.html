Whitening

Let S be a real symmetric matrix whose quadratic form is bounded below: b |x|^2 <= x S x^T for every row vector x, with b > 0. If S = P^T diag (d) P is its spectral decomposition, the matrix W = diag (d)^(-1/2) P whitens S: W S W^T = 1 (whitening_mxP), and |x W| <= |x| / sqrt b for every row vector x (frobenius_whitening_mx). For b = 1, W does not increase norms (whitening_exists).

whitening_mx Sdiag_mx (\row_i (Num.sqrt (d 0 i))^-1) *m P for the chosen spectral decomposition S = P^T diag_mx d P (sym_spectralmx, sym_spectral_diag)
