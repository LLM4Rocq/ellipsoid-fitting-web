Lemma 2.11 of Koehler and Sohn (arXiv 2608.27372, lines 1386-1441): the cost of a theta-self-concordant barrier B >= 0 in the least squares value is controlled by the contraction toward a reference point. Below, D is convex and relatively open with directions V, B is a theta-self-concordant barrier on D with theta >= 0 and B >= 0 on D, theta_ref is in D, b_ref is real, lambda, beta >= 0, gamma > 0 and 0 < eps < 1. F_Z is ls_objective, Phi_Z(D; beta) is ls_value and Phi_Z(D, B; beta, gamma) is ls_barrier_value (least_squares.v).

  • ls_objective_convex: F_Z is convex in (theta, b).
  • barrier_removal, Lemma 2.11: for every n-tuple of features Z,
    0 <= Phi_Z(D, B; beta, gamma) - Phi_Z(D; beta)
  <= eps F_Z(theta_ref, b_ref; beta) + gamma B theta_ref
     + gamma theta ln (1 / eps).
  • barrier_removal_compare, (2.15): for two tuples W and G,
    |Phi_W(D; beta) - Phi_G(D; beta)|
  <= |Phi_W(D, B; beta, gamma) - Phi_G(D, B; beta, gamma)|
     + eps (F_W + F_G)(theta_ref, b_ref; beta) + 2 gamma B theta_ref
     + 2 gamma theta ln (1 / eps).

Lemma barrier_removal_compare n (W G : n.-tuple 'rV[R]_N)
