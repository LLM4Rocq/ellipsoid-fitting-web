Two bounds for real symmetric matrices

  • psd_square_gap, a gap from the square: if B is symmetric and positive semidefinite and k x^T B x <= |B x|^2 for every column x, then k |x|^2 <= x^T B x for every x orthogonal to the kernel of B. In an eigenbasis of B (symmetric_spectral) the hypothesis says that every eigenvalue is 0 or at least k.
  • opnorm_row_sum, the Schur test for symmetric matrices: if B is symmetric, rho >= 0 and sum_j |B_ij| <= rho for every row i, then opnorm B <= rho.
  • mulmx_col_mxdot and mxdot_mulmx_sum write (P x)_i and x^T B x as sums.

This file is a Rocq formalization, in general form, of two steps of the credited argument of the proposition 'Gap and covariance under scaled interactions and fields' of 'Cutoff throughout the high-temperature Sherrington-Kirkpatrick phase' (family 227 of the OpenAI math collection, revision 1581d4cbd, appendices/entropy.tex): the row-sum bound for the operator norm of a symmetric matrix, and the gap read from the inequality |A f|^2 >= kappa <f, A f>. Target T4 of phase 12 (AGENTS.md, section Phase 12) uses both. The file follows no Lean module.
