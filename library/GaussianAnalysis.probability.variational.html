For a law mu on the line with a finite second moment, the upper partial moments m(w) = E (X - w)_+ and s(w) = E (X - w)_+^2 solve the variational problem of Koehler and Sohn (arXiv 2608.27372, Lemmas 5.7 and 5.8): for c > -1 and z real, the equation w + z = c m(w) has a unique solution w, and

sup { (E (X + z) f(X))_+^2 / (E f(X)^2 + c (E f(X))^2) :
      f >= 0, E f(X)^2 < oo, E f(X) > 0 }  =  s(w) + c m(w)^2,

attained at f(x) = (x - w)_+ when the right-hand side is positive.

Main results:

  • upper_moment1_lipschitz: 0 <= m(w1) - m(w2) <= w2 - w1 for w1 <= w2; upper_moment1_ge: E X - w <= m(w); upper_moment1_le: m(w) <= E X^2 / (4 w) for w > 0; upper_moment1_gt0: m(w) > 0 if mu(]b, +oo[) > 0 for some b > w; upper_moment2_taylor: |s(w + h) - s(w) + 2 h m(w)| <= h^2, so s' = -2 m; upper_moment2_lipschitz: 0 <= s(a) - s(b) <= (b - a) (m(a) + m(b)) for a <= b; upper_moment2_eq0: m(w) = 0 forces s(w) = 0.
  • Lemma 5.7, first part, for c > -1: upper_cutoffE (w = upper_cutoff mu c z solves w + z = c m(w)), upper_cutoff_unique (it is the only solution), upper_cutoff_le (w' + z <= c m(w') if and only if w' <= w); upper_cutoff_growth: (w2 - c m(w2)) - (w1 - c m(w1)) >= min(1, 1 + c) (w2 - w1) for w1 <= w2.
  • upper_energy_decr: E = s + c m^2 is strictly decreasing where m > 0, E(w1) - E(w2) >= 2 min(1, 1 + c) m(w2) (w2 - w1) for w1 <= w2, hence upper_energy_lt: E(w2) < E(w1) for w1 < w2 with m(w2) > 0; upper_energy_lipschitz: |E(a) - E(b)| <= 2 (1 + |c|) m(a) (b - a), hence upper_energy_continuous; upper_energy_ge: E(w) >= (1 + c) m(w)^2.
  • Lemma 5.7 (upper_variational): the supremum of upper_ratio mu c z f over f in upper_admissible mu is upper_value mu c z. upper_variational_le: (E (X + z) f(X))_+^2 <= upper_value mu c z (E f(X)^2 + c (E f(X))^2) for every measurable f >= 0 with f^2 integrable; upper_variational_attained: E (X + z) p(X) = upper_value mu c z for p(x) = (x - w)_+; upper_admissible_cutoff, upper_ratio_cutoff: p is admissible and optimal when the value is positive.
  • upper_value_nondecr, upper_value_incr: z |-> upper_value mu c z is nondecreasing, and strictly increasing where it is positive.
  • Lemma 5.8: upper_cutoff_stability, upper_value_stability bound the cutoff and the value of mu by those of nu through the values of m and s at the cutoff of nu only; upper_cutoff_cvg, upper_value_cvg: if m_{mu_n} and s_{mu_n} converge to m_mu and s_mu at the cutoff of mu, the cutoffs and the values of mu_n converge to those of mu.
  • Symmetric laws (the scalar part of Lemma 5.9), mu invariant under x |-> -x: integrable_sym, Rintegral_sym, Rintegral_id_sym (f(-X) is integrable with f(X), E f(-X) = E f(X), E X = 0); upper_moment1_sym: m(-w) = m(w) + w; upper_moment2_sym: s(-w) + s(w) = E X^2 + w^2; upper_cutoff_dual: the cutoff of (-c/(1 + c), -z/(1 + c)) is minus that of (c, z); upper_value_dual: the two values add up to E X^2 + z^2 / (1 + c); upper_variational_sym_le: at z = 0 the bound of upper_variational_le holds without the positive part, (E X f(X))^2 <= upper_value mu c 0 (E f(X)^2 + c (E f(X))^2) (Proposition 5.10 (ii)).
  • The energy of a two-sided clip: clip_energy mu C t = s(-t) + s(C t), the mean squared distance from X to [t, C t] for a symmetric law (clip_energyE), and clip_value mu C, its infimum over t >= 0. clip_energy_taylor: its derivative in t is 2 (m(-t) - C m(C t)); clip_value_attained: a point t0 >= 0 where the derivative changes sign from <= 0 to >= 0 is a minimum; clip_energy_C, clip_value_nincr: nonincreasing in C, with a Lipschitz bound. taylor_nincr, taylor_ndecr: a function with a Taylor bound |F(t + h) - F(t) - h g(t)| <= K h^2 is monotone where g has a sign (a discrete integration).
  • Tools: Rintegral_sqr_le ((E g)^2 <= E g^2), discriminant_le (a quadratic a + 2 b t + k t^2 >= 0 for all t has b^2 <= a k), upper_form_ge0 (E f^2 + c (E f)^2 >= 0 for c > -1), integrable_of_sqr, integrable_mul_sqr, integrable_quad_bound, Rintegral_prob_cst.
  • Finite samples: empirical s is the law of an element of a nonempty list s drawn uniformly, a probability (the Dirac mass at 0 for the empty list), with ge0_integral_empirical, integrable_empirical, Rintegral_empirical: integrals against it are averages over s. For g : 'I_d -> R, empirical_fun g is the empirical law of its values and upper_moment_empirical_fun gives m and s as averages.
