Products of probability measures on tuples, that is the laws of tuples of independent random elements, and Lindeberg's replacement principle (lindeberg_replacement): if replacing the law of one coordinate changes the expectation of a bounded measurable function F by at most B_i, uniformly in the other coordinates, then replacing all the laws changes it by at most the sum of the B_i.

tuple_cons pthe tuple p.1 :: p.2 of size n.+1, for p : T * n.-tuple T
tuple_prod mu nthe product of the probability measures mu 0, ..., mu n.-1 on n.-tuple T: the law of n independent random elements with laws mu 0, ..., mu n.-1
tuple_set x i tthe tuple x with its coordinate i replaced by t

tuple_prod mu n is the law of n independent random elements with laws mu 0, ..., mu (n-1), on n.-tuple T; integrals against it are iterated integrals (Fubini).none
lindeberg_replacement
Lindeberg's replacement principle: for F bounded and measurable on n.-tuple T, if replacing the law mu i of coordinate i by nu i changes the expectation of F by at most B i, uniformly in the other coordinates, then replacing all of them changes it by at most B 0 + ... + B (n-1).none: the proof keeps its own row replacement, Loss/Replacement, which works with the iterated expectation on lists; a bridge would need tuple_prod of the standard law to be identified with gaussian_product_law and a reshaping of rows

forall [d : measure_display] [T : measurableType d] [R : realType] 
  [n : nat] [mu nu : nat -> probability T R] [F : n.-tuple T -> R]

(forall x : n.-tuple T, `|F x| <= C) ->
(forall (i : 'I_n) (x : n.-tuple T),
 `|\int[mu i]_t F (tuple_set x i t) - \int[nu i]_t F (tuple_set x i t)| <= B i) ->

Lindeberg's replacement principle.

Main result, as the README states it

Lindeberg's replacement principle: for F bounded and measurable on n.-tuple T, if replacing the law mu i of coordinate i by nu i changes the expectation of F by at most B i, uniformly in the other coordinates, then replacing all of them changes it by at most B 0 + ... + B (n-1).

Used in theories/ by: none: the proof keeps its own row replacement, Loss/Replacement, which works with the iterated expectation on lists; a bridge would need tuple_prod of the standard law to be identified with gaussian_product_law and a reshaping of rows

    (F : n.-tuple T -> R) (C : R) (B : nat -> R) :
  measurable_fun setT F -> (forall x, `|F x| <= C) ->
  (forall (i : 'I_n) (x : n.-tuple T),
    `|\int[mu i]_t F (tuple_set x i t) - \int[nu i]_t F (tuple_set x i t)|
      <= B i) ->
