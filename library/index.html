GaussianAnalysisRocq · MathComp · MathComp-Analysis

A Rocq library on Gaussian measures, Gaussian comparison and concentration inequalities, and the linear algebra and probability tools they need. It is written over an arbitrary R : realType, in the style of MathComp-Analysis, so that parts of it can later be proposed to MathComp-Analysis. It does not depend on the ellipsoid fitting papers. The proofs of the two theorems in theories/ and extension/ use it at Stdlib's R.

Conventions

  • Reals. Every result is stated for an arbitrary R : realType, or a weaker structure such as realFieldType when that is enough. No file requires Stdlib's Reals, Lra, Psatz or MathComp's Rstruct: make check rejects them in library/.
  • Vocabulary. MathComp's: row and column vectors 'rV[R]_n and 'cV[R]_n, matrices 'M[R]_(m, n), `|x|, Num.sqrt, expR, ln, n%:R, \sum, and the measures, integrals and probability of MathComp-Analysis (measure, lebesgue_integral, probability, normal_distribution). No lists of coordinates.
  • Tactics. From mathcomp Require Import arithmetic_tactic provides lra, nra and psatz on any real field; ring_tactic and field_tactic provide ring and field.
  • Names and style. MathComp's naming conventions for lemmas, ssreflect proof style, lowercase file names, and a documentation header at the top of each file in MathComp's format: each definition and notation with a one-line reading.
  • Axioms. No Admitted, Axiom or Parameter. MathComp's classical axioms (boolp) may be used.

How to read this documentation

  • Pages. Each file of the library has a page: its documentation header, the rows of the table of main results that concern it, then its declarations in source order, inside their sections. A section shows the Context, Variable and Hypothesis lines that its declarations may use.
  • Signatures. The code block of a lemma is its type as Rocq prints it with About, after the sections are closed: it lists every argument, implicit ones in braces (maximal) or brackets (non-maximal), and the hypotheses. The statement as written in the source, inside its section, is one click away. A definition shows its type and its body.
  • Links. In the source statements, every name links to its declaration through the .glob files that Rocq writes when it compiles, so the links are exact. In the printed signatures, the names that the source statement uses are linked the same way; other names are linked when they are unique in the library. Names of MathComp and MathComp-Analysis show their full path on hover.
  • Local declarations. Let definitions live only inside their section, and Local lemmas are not imported with their file. They are hidden by default; a checkbox on each page shows them.
  • Used by. Under each declaration, the list of the declarations of both packages whose statement or proof refers to it.
  • Written for this documentation. The guide at the top of each directory page was written from the sources and the README, then checked against the Rocq statements by an independent reading. The classical results on this page are named as in the README rows. Everything else is extracted from the sources mechanically.

To install them in a new opam switch:

opam switch create ellipsoid-fitting ocaml-base-compiler.5.3.0
opam repo add rocq-released https://rocq-prover.org/opam/released
opam repo add coq-released https://coq.inria.fr/opam/released
opam install --deps-only ./rocq-ellipsoid-fitting.opam

Then, from the repository root:

make check ROCQ_SWITCH=ellipsoid-fitting JOBS=8   # the switch created above
make check ROCQ_SWITCH= JOBS=8                    # the rocq on your PATH
