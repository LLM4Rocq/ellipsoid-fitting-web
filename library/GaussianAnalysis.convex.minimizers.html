The convex analysis that the Lindeberg argument of Koehler and Sohn (arXiv 2608.27372, Theorem 2.9) needs, for the objective

F(theta, b) = s sum_(i in P) (b - <Z_i, theta>)^2
              + beta (lambda |theta|^2 + b^2) + gamma B theta

on D x R (ls_barrier_objective of least_squares.v), where D is relatively open and convex with directions V (rel_open_convex), B >= 0 is a self-concordant function on D (sc_function), s >= 0 and lambda, beta, gamma > 0. D need not be bounded: the ridge term makes F coercive.

ls_grad Z P s lambda beta theta b h cthe first variation of the ridge objective at (theta, b) in the direction (h, c)
ls_bopt Z P s beta thetathe b that minimizes the ridge objective for a fixed theta

Main results:

  • vspace_orthonormal: every subspace V of 'rV[R]_N is the row space of a matrix E with orthonormal rows (E E^T = I, of \dim V rows); closed_vspace: V is closed.
  • rel_open_convex_closure: for z in D and y in the closure of D, y - z is in V and z + t (y - z) is in D for 0 <= t < 1.
  • sc_sublevel_closed, sc_minimizer: for g continuous, convex on D and nonnegative, the sublevel sets of g + gamma B in D are closed (the barrier tends to +oo at the relative boundary); if moreover g z >= kappa |z|^2 with kappa > 0, then g + gamma B attains its minimum on D.
  • ls_barrier_minimizer: F attains its minimum on D x R.
  • ls_first_order: at a minimizer (theta, b), the derivative of F along every direction (h, c) of V x R is 0.
  • ls_taylor (paper, (2.17)-(2.18)): at a minimizer, for h in V, F (theta + h) (b + c) - F theta b = ridge(h, c) + gamma bregman_div B (theta + h) theta, ridge being the quadratic part of F.
  • quad_response (paper, (2.19)): for H symmetric positive definite, a row vector a and nn > 0, the infimum over u of u H u^T / 2 + (r + <a, u>)^2 / (2 nn) is r^2 / (2 (nn + l)) with l = a H^-1 a^T, attained at u0 = - (r / (nn + l)) a H^-1, where u0 H u0^T = l r^2 / (nn + l)^2; and 2 <a, u> - u H u^T <= l for all u.

lemma quad_response main result source, line 575 
forall {R : realType} {k : nat} [H : 'M_k] (a : 'rV_k) (r : R) [nn : R],
posdefmx H ->
0 < nn ->
let l := mxdot a (a *m invmx H) in
let u0 := - (r / (nn + l)) *: (a *m invmx H) in
[/\ 0 <= l, forall u : 'rV_k, 2 * mxdot a u - mxdot u (u *m H) <= l,
    forall u : 'rV_k,
    r ^+ 2 / (2 * (nn + l)) <= mxdot u (u *m H) / 2 + (r + mxdot a u) ^+ 2 / (2 * nn),
    mxdot u0 (u0 *m H) / 2 + (r + mxdot a u0) ^+ 2 / (2 * nn) = r ^+ 2 / (2 * (nn + l))
  & mxdot u0 (u0 *m H) = l * r ^+ 2 / (nn + l) ^+ 2]

For H symmetric positive definite, a row vector a and nn > 0, the quadratic problem inf_u { u H u^T / 2 + (r + <a, u>)^2 / (2 nn) } has value r^2 / (2 (nn + l)), l = a H^-1 a^T, attained at u0 = - (r / (nn + l)) a H^-1 (paper, (2.19)); and l = sup_u (2 <a, u> - u H u^T).
