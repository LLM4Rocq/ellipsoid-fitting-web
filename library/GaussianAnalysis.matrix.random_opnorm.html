A bound by nets and the moment generating function of sums of independent subexponential variables, used for Lemma 4.3 of Koehler and Sohn (arXiv 2608.27372, lines 4604-4615) in place of the matrix Bernstein inequality that the paper cites; it gives the bound without the logarithmic factor.

Main results:

  • Quadratic forms, mxdot_psd_le: for S symmetric positive semidefinite and any square A, |<A, S>| <= opnorm (sym_part A) tr S, where <., .> is the Frobenius product mxdot; sym_part_form, mxdot_sym_part: v^T A v and <A, S> only see the symmetric part.
  • Nets, unit_ball_quarter_net: the unit ball of 'cV[R]_n has a 1/4-net of at most (18 e)^n of its points; opnorm_sym_part_net: for such a net V, opnorm (sym_part A) <= 2 max_{v in V} |v^T A v|.
  • Maximal inequality, subexponential_max_sum: for x of law tuple_prod mu n, a finite family of functions g_v, each centered and subexponential with constant L under every mu i, and |a_i| <= 1,
    E max_v |sum_i a_i g_v(x_i)| <= 8 L (sqrt (n Lam) + Lam)

    with Lam = 1 + ln (1 + 2 N), N the size of the family. Proof: the moment generating function of each sum (subexponential_sum_mgf of subgaussian.v), expR_bigmax_le (exp (l max_v |S_v|) is at most 1 + sum_v (exp (l S_v) + exp (- l S_v))), expectation_le_ln_mgf (if E exp (l Z) <= B with ln B >= 1, then E Z <= ln B / l, from e^y >= 1 + y), and a choice of l.

  • Random matrices, opnorm_sum_subexponential: for x of law tuple_prod mu n and Y : T -> 'M[R]_m whose quadratic forms v^T Y v (|v| <= 1) are centered and subexponential with constant L under every mu k, there are measurable functions N a such that, for all weights with |a_k| <= 1, opnorm (sym_part (sum_k a_k Y(x_k))) <= N a x and
    E N a <= 96 L (sqrt (n (m + 1)) + m + 1).

    N a x is 2 max_{v in V} |v^T (sum_k a_k Y(x_k)) v| on the net V; net_log_le bounds the logarithm of the size of the net by 6 (m + 1).

theorem opnorm_sum_subexponential main result source, line 456 
forall [d : measure_display] [T : measurableType d] [R : realType]
  [mu : nat -> probability T R] [n m : nat] [Y : T -> 'M_m] [L : R],
0 < L ->
(forall (v : 'cV_m) (k : nat),
 frobenius v <= 1 -> (k < n)%N -> subexponential (mu k) (fun t : T => mxdot v (Y t *m v)) L) ->
(forall (v : 'cV_m) (k : nat),
 frobenius v <= 1 -> (k < n)%N -> \int[mu k]_t mxdot v (Y t *m v) = 0) ->
exists N : (nat -> R) -> n.-tuple T -> R,
  forall a : nat -> R,
  (forall k : nat, (k < n)%N -> `|a k| <= 1) ->
  [/\ measurable_fun [set: n.-tuple T] (N a),
      forall x : n.-tuple T, opnorm (sym_part (\sum_(k < n) a k *: Y (tnth x k))) <= N a x
    & (\int[tuple_prod mu n]_x (N a x)%:E <=
       (96 * L * (Num.ExtraDef.sqrtr (n%:R * m.+1%:R) + m.+1%:R))%:E)%E]

The operator norm of a weighted sum of independent random matrices whose quadratic forms are centered and subexponential, through a measurable majorant (the operator norm is a supremum over the unit ball), the same for all weights.

Main result, as the README states it

For x of law tuple_prod mu n and Y : T -> 'M[R]_m whose quadratic forms v^T Y v (|v| <= 1) are centered and subexponential with constant L under every mu k, there are measurable N a with opnorm (sym_part (sum_k a_k Y(x_k))) <= N a x and E N a <= 96 L (sqrt (n (m + 1)) + m + 1) for all weights with |a_k| <= 1. Unlike the matrix Bernstein inequality, the bound has no logarithmic factor.
