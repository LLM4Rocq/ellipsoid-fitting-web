-ln det is a self-concordant barrier with parameter n on the trace slices of the cone of positive definite n x n matrices (Nesterov-Nemirovskii, Proposition 5.4.5), and -ln det (A - m I) - ln det (M I - A) is a 2n-self-concordant barrier on the matrices of trace n with m I < A < M I. This is Lemma 2.8 of Koehler and Sohn (arXiv 2608.27372). Matrices are seen as row vectors of size n * n through mxvec, so that self_concordant.v applies; the inner product of mxvec A and mxvec B is the Frobenius product mxdot A B.

posdefmx AA is symmetric positive definite: 0 < x A x^T for every row vector x != 0
pd_slice n sthe matrices A (as mxvec A) that are positive definite with trace s
logdet_barrier n x- ln (det (vec_mx x)), for x : 'rV[R]_(n * n)
pd_slice2 n m Mthe matrices A (as mxvec A) of trace n with A - m I and M I - A positive definite
logdet_barrier2 n m M x- ln det (A - m I) - ln det (M I - A) + n ln ((1 - m) (M - 1)), with A = vec_mx x
sym_traceless nthe subspace of the mxvec of the symmetric matrices of trace 0
logsum l c tc - sum_i ln (1 + t l_i), for l : 'rV[R]_k

Main results:

  • logdet_line: for A positive definite and U symmetric, -ln det (A + t U) = c - sum_i ln (1 + t l_i) whenever A + t U is positive definite, which happens exactly when every 1 + t l_i is positive; tr (A^-1 U) and tr ((A^-1 U)^2) are the sums of the l_i and of their squares (simultaneous diagonalization, congruence_diag).
  • logsum_sc_barrier: a function that is c - sum_i ln (1 + t l_i), i < k, along every line through D, and whose first and second derivatives at each point are a linear and a bilinear form, is a k-self-concordant barrier on D.
  • rel_open_convex_pd_slice, logdet_sc_barrier: pd_slice n s is convex and relatively open with directions sym_traceless n, and logdet_barrier n is an n-self-concordant barrier on it.
  • logdet_barrier_ge0, logdet_barrier_one: logdet_barrier n >= 0 on pd_slice n n, with value 0 at the identity (det A <= (tr A / n)^n).
  • rel_open_convex_pd_slice2, logdet2_sc_barrier: for all m and M, pd_slice2 n m M is convex and relatively open with directions sym_traceless n, and logdet_barrier2 n m M is a 2n-self-concordant barrier on it.
  • logdet_barrier2_ge0, logdet_barrier2_one: if m < 1 < M, then logdet_barrier2 n m M >= 0 on pd_slice2 n m M, with value 0 at the identity.

Along a line through a positive definite A in a symmetric direction U, -ln det (A + t U) = c - sum_i ln (1 + t l_i), where l is the spectrum of U relative to A; A + t U is positive definite exactly when every 1 + t l_i is positive, and tr (A^-1 U) and tr ((A^-1 U)^2) are the sums of the l_i and of their squares.

A function that equals c - sum_(i < k) ln (1 + t l_i) along every line through D (with D convex and relatively open, the l_i and c depending on the line), and whose first and second derivatives at each point of D are a linear and a bilinear form, is a k-self-concordant barrier on D.
