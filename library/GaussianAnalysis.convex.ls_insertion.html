The deterministic part of the Lindeberg argument of Koehler and Sohn (arXiv 2608.27372, proof of Theorem 2.9, lines 1637-2116 and 3809-4225). Fix features x_1, ..., x_n in 'rV[R]_N and an index i, a convex set D that is relatively open with directions V, a self-concordant function B >= 0 on D, and lambda, beta, gamma > 0. The leave-one-out objective is

F^(i)(theta, b) = (2 n)^-1 sum_(j <> i) (b - <x_j, theta>)^2
                  + beta (lambda |theta|^2 + b^2) + gamma B theta,

with a minimizer (theta_m, b_m) on D x R (ls_barrier_minimizer). Inserting a feature z at the place i gives the value of the full problem (ls_barrier_value of tuple_set x i z), and the insertion cost is Delta(z) = that value minus F^(i)(theta_m, b_m). Directions of V x R are written in coordinates w = (c, y) in 'rV[R]_(1 + k), for a matrix E whose k rows form an orthonormal basis of V: the direction is (y E, c).

ins_alpha E zthe row (1, - z E^T): <ins_alpha E z, w> is c - <z, y E>, the change of the residual of z
ins_hform ... w w'the Hessian of F^(i) at the minimizer, as a bilinear form of the coordinates
ins_hessian ...its matrix H^(i)
ins_ell ... zl_i(z) = <alpha(z), H^-1 alpha(z)>
ins_r ... zr_i(z) = b_m - <z, theta_m>, the residual
ins_cost ... zDelta_i(z), the insertion cost
ins_c0, ins_v, ins_Tthe coefficients of l_i as a quadratic polynomial

Main results:

  • ins_hessian_pd (Lemma 4.1): H^(i) is positive definite, with w H w^T >= 2 beta (lambda |y|^2 + c^2); ins_form_le: for a linear form w |-> c c_w + <y, h_w>, its squared H^-1 norm is at most c^2 / (2 beta) + |y|^2 / (2 beta lambda).
  • ins_taylor: the inserted objective at (theta_m + h_w, b_m + c_w) exceeds F^(i)(theta_m, b_m) by w H w^T / 2 + (r + <alpha, w>)^2 / (2 n) plus gamma times the third order remainder of B.
  • ins_cost_bounds (2.20): 0 <= Delta(z) <= r(z)^2 / (2 n).
  • ins_cost_upper, ins_cost_lower (Lemma 4.2): if 36 <= n gamma and r(z)^2 <= sqrt (n gamma), then Delta(z) differs from r(z)^2 / (2 (n + l(z))) by at most 2 |r(z)|^3 / (n sqrt (n gamma)).
  • ins_cost_quadratic (Proposition 2.14, (2.23), pointwise): if 36 <= n gamma, then for every z,
    |Delta(z) - r(z)^2 / (2 (n + l(z)))|
  <= (2 + 3 r(z)^4) / (n sqrt (n gamma)).
  • ins_ell_quadratic, ins_c0_bounds, ins_v_bound, ins_T_bounds, ins_T_sym, ins_T_frobenius (the structure behind Proposition 2.16): l(z) = c0 - 2 <v, z> + z T z^T with T symmetric, 0 <= c0 <= 1 / (2 beta), |v|^2 <= k / (4 beta^2 lambda), 0 <= z T z^T <= |z|^2 / (2 beta lambda) and |T|_F^2 <= k / (4 beta^2 lambda^2).
  • ins_size_le (Proposition 2.14, (2.21)): for theta_ref in D, beta (lambda |theta_m|^2 + b_m^2) <= (2 n)^-1 sum_(j <> i) <x_j, theta_ref>^2 + beta lambda |theta_ref|^2 + gamma B theta_ref.
