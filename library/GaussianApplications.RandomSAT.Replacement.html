S is a set of assignments on n variables.

  • forced S is the set of the variables on which all the elements of S agree, and is empty when S is empty, as b(H) = 0 for an unsatisfiable H in the manuscript; frozen S s0 is the set of the variables on which they all agree with s0 (forced_frozen).
  • A clause empties a nonempty S exactly when its variables are forced and its signs oppose the forced values (kills_frozen, frozen_kills), so these clauses correspond to the sets of k forced variables (card_kills). With kfrac b v r = 'C(b, r) / ('C(v, r) 2^r), the killing probability of a nonempty S is kfrac #|forced S| n k (killE_forced): the q_r(H) = (b)_r / (2^r (v)_r) of the manuscript.
  • Bounds on kfrac: kfrac b v r <= (b / (2 v))^r for b, r <= v and v > 0 (kfrac_le_pow), the recursion in r (kfrac_succ) and its lower bound (kfrac_succ_lower), and kfrac b v r <= 1 / (v + 1) when b <= r and 1 <= r < v, for few forced variables (kfrac_small).
  • kill_replacement, the lemma 'Replacing a (k-1)-clause': for 1 <= r < v, a > 0 with 1 / (v + 1) <= a^-r and g >= 2 (r + 1) a, the probability that a block of g independent clauses of size r + 1 empties S is at least kill r S - a^-r. The manuscript takes r = k - 1, v = n - 1, a = n^(1/k) and g = ceil(2 k n^(1/k)); the lemma assumes only the inequalities that these choices satisfy.

Replacing a shorter clause by a block of g clauses: the probability that the block kills S is at least the probability that one clause of size r kills it, minus a^-r.
