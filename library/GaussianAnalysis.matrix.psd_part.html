The positive part of a symmetric matrix

For a real symmetric matrix A with a spectral decomposition A = P^T diag(d) P, P orthogonal, the positive part psd_part A = P^T diag((d_i)_+) P is the nearest positive semidefinite matrix to A in the Frobenius norm. It is defined from the decomposition chosen by sym_spectralmx and sym_spectral_diag of real_spectral.v, and does not depend on that choice (psd_partE).

G8 (Koehler and Sohn, Lemma 5.14 and Proposition 5.15) handles spectral functions through psd_part, which is equivariant under orthogonal conjugation: Lemma 5.13 (random_matrix/goe_rotation.v) can be stated for any F with F (Q W Q^T) = Q F(W) Q^T for every orthogonal Q, such as W |-> psd_part (W - w(W) I) for a w(W) that depends only on the spectrum.

  • psd_conj: P^T diag(d) P >= 0 for d >= 0; mxdot_psd_ge0: <S, T> >= 0 for S, T >= 0.
  • psd_nearest: for A = P^T diag(d) P and S >= 0, |A - S|^2 >= |A - A_+|^2 + |A_+ - S|^2; psd_part_nearest, psd_part A is the nearest positive semidefinite matrix; psd_partE, psd_part A = P^T diag((d_i)_+) P for every spectral decomposition; psd_part_psd.
  • psd_part_conj: psd_part (Q A Q^T) = Q (psd_part A) Q^T, Q orthogonal.
  • psd_part_moreau: A = psd_part A - psd_part (- A) with <psd_part A, psd_part (- A)> = 0.
  • psd_part_nonexpansive: |psd_part A - psd_part B|_F <= |A - B|_F; psd_partZ: psd_part (c A) = c psd_part A for c >= 0.
  • spec_shift_decomposition, trace_psd_part_shift and frobenius_psd_part_shift: tr psd_part (A - w I) = sum_i (spec A i - w)_+ and |psd_part (A - w I)|_F^2 = sum_i (spec A i - w)_+^2, with spec of matrix/von_neumann.v; mxdot_psd_part_shift: <A, psd_part (A - w I)> = sum_i spec A i (spec A i - w)_+.
  • char_poly_conj_diag, spec_conj_diag: P^T diag(v) P has the characteristic polynomial prod_i (X - v_i), so its sorted spectrum is v when v is decreasing; spec_scale: spec (c A) = c spec A for c >= 0.
  • spec_psd_ge0, sum_spec_trace: the eigenvalues of a positive semidefinite matrix are nonnegative; they sum to the trace.
  • mxdot_spec_le: von Neumann's inequality for the Frobenius pairing, <A, B> <= sum_i spec A i spec B i for A and B symmetric.

The characteristic polynomial of P^T diag(v) P, P orthogonal.

Main result, as the README states it

For P orthogonal, P^T diag(v) P has the characteristic polynomial prod_i (X - v_i), so its sorted spectrum is v when v is decreasing, and spec (c A) = c spec A for c >= 0. The eigenvalues of a positive semidefinite matrix are nonnegative and sum to the trace; von Neumann's inequality in the form <A, B> <= sum_i spec A i spec B i for A, B symmetric.
