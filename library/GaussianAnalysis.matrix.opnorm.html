The operator norm of A : 'M[R]_(m, n) is its norm as a linear map x |-> A *m x from 'cV[R]_n to 'cV[R]_m, both with the Euclidean norm frobenius. It is characterized by the inequality frobenius (A *m x) <= b * frobenius x (opnorm_leP) and by the bilinear inequality `|mxdot y (A *m x)| <= b * frobenius y * frobenius x (opnorm_bilinearP). For a symmetric matrix, it is the smallest b such that `|mxdot x (A *m x)| <= b * mxdot x x for every x (opnorm_symP), and the largest absolute value of an eigenvalue (opnorm_spectral). For a symmetric matrix and an even exponent p > 0, tr (A ^+ p) <= t ^+ p, or mxdot x (A ^+ p *m x) <= t ^+ p * mxdot x x for every x, gives opnorm A <= t (opnorm_le_trace_exp, opnorm_le_form_exp). The operator norm lies between the norm mx_norm of MathComp-Analysis and the Frobenius norm: mx_norm A <= opnorm A <= frobenius A (mx_norm_le_opnorm, opnorm_le_frobenius).

opnorm Athe operator norm of A, the supremum of frobenius (A *m x) over the columns x with frobenius x <= 1

Main result, as the README states it

For a symmetric matrix and an even exponent p > 0, opnorm A ^ p <= tr(A^p); so tr(A^p) <= t^p with t >= 0 gives opnorm A <= t, and so does x^T A^p x <= t^p x^T x for all x.
