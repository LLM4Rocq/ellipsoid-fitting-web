GaussianAnalysis/matrix/lambda_max

The largest eigenvalue of a real square matrix

lambda_max A is the supremum of the quadratic form mxdot x (A *m x) over the unit vectors x of 'cV[R]_n, in the conventions of opnorm (opnorm.v) and rayleigh_max (real_spectral.v): column vectors, the Frobenius inner product mxdot. For a symmetric matrix it is the largest eigenvalue. For n = 0 there is no unit vector and lambda_max A = 0, the supremum of the empty set (lambda_max_dim0).

The definition is alone in the section lambda_max, which is frozen with the statement of target T3 of phase 12 (AGENTS.md, section Phase 12; the sharp upper edge of the GOE): the source checker of scripts/ compares its code and the Require commands of this file with the acceptance commit fc76edf. The lemmas below it may grow. The file is a Rocq formalization of the largest eigenvalue lambda_max(W) of the credited argument of the proof of the proposition 'Good disorder' of 'Cutoff throughout the high-temperature Sherrington-Kirkpatrick phase' (family 227 of the OpenAI math collection, revision 1581d4cbd, appendices/entropy.tex). It follows no Lean module: the Lean modules of the collection write lambda_max(W) as the supremum of a Gaussian process over the unit ball and have no separate definition of the largest eigenvalue.

Proved:

  • lambda_max_ub, lambda_max_form: x^T A x <= lambda_max A for every unit x, and x^T A x <= lambda_max A x^T x for every x.
  • lambda_max_le: for n > 0, lambda_max A <= b as soon as x^T A x <= b for every unit x; lambda_max_attained: for n > 0, the supremum is attained at a unit vector (rayleigh_max).
  • lambda_max_eigenvector, eigenvalue_le_lambda_max: for n > 0 and A symmetric, lambda_max A is an eigenvalue of A; for every A, every eigenvalue of A with a unit eigenvector is at most lambda_max A.
  • lambda_max_opnorm, lambda_maxD: lambda_max A <= opnorm A, and lambda_max (A + B) <= lambda_max A + lambda_max B.
  • lambda_max_lipschitz, lambda_max_lipschitz_frobenius: `|lambda_max A - lambda_max B| <= opnorm (A - B) <= frobenius (A - B).
  • opnorm_lambda_max: for a symmetric A, opnorm A = Num.max (lambda_max A) (lambda_max (- A)).
lambda_max Athe supremum of mxdot x (A *m x) over the columns x with mxdot x x = 1; the largest eigenvalue of a symmetric A

It bounds x^T A x for unit x, and x^T A x <= lambda_max A x^T x for all x; for n > 0 it is the least such bound and is attained at a unit vector.
