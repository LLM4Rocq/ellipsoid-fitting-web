The maximizer of a trace-penalized quadratic on a closed convex set

For c > -1 and real n x n matrices H and S, let trace_quad c H S = 2 <H, S> - |S|_F^2 - (c / n) (tr S)^2, with the Frobenius product <., .> and norm |.|_F of matrix/euclidean.v. With A = trace_scale c, that is A S = S + (c / n) tr(S) I, the quadratic part is <S, A S> = |S|_F^2 + (c / n) (tr S)^2. Since (tr S)^2 <= n |S|_F^2, it is coercive: <S, A S> >= min(1, 1 + c) |S|_F^2. So trace_quad c H is strictly concave, and it has a unique maximizer X(H) on every nonempty closed convex set K of matrices. Since trace_quad c H S = <H, A^-1 H> - <S - A^-1 H, A (S - A^-1 H)>, X(H) is the nearest point of K to A^-1 H = H - (c / (1 + c)) (tr H / n) I for the scalar product <S, A T> = <S, T> + (c / n) tr S tr T, with A^-1 = trace_scale (- c / (1 + c)). It is not the nearest point of K to H: for K the whole space, X(H) = A^-1 H. X(H) is computed by the projection of convex/moreau.v. U = trace_scale (sqrt (1 + c) - 1) multiplies the component of a matrix along the identity by sqrt (1 + c) and fixes the matrices of trace 0; U U = A, and X(H) = U^-1 Pi_{U K}(U^-1 H), with Pi_{U K} the Frobenius projection onto U K. The definition applies U^-1 = trace_scale (1 / sqrt (1 + c) - 1) to H, projects onto U K in the coordinates of mxvec, and applies U^-1 to the result.

  • trace_scaleK: trace_scale a (trace_scale b S) = trace_scale ((1 + a) (1 + b) - 1) S, so trace_scale a is invertible when a != -1; trace_scale_adj, it is self-adjoint for the Frobenius product; mxtrace_scale, tr (trace_scale a S) = (1 + a) tr S.
  • mxtrace_sqr_le: (tr S)^2 / n <= |S|_F^2; trace_pen_ge, the coercivity above, for every real c.
  • trace_quad_expand: the exact expansion of trace_quad c H at any X: trace_quad c H S - trace_quad c H X equals 2 <H - X - (c / n) tr(X) I, S - X> minus |S - X|_F^2 + (c / n) (tr (S - X))^2.

In what follows, K is a set of n x n matrices that is closed in the coordinates of mxvec, convex and nonempty, c > -1 and X = trace_argmax K c H.

  • trace_argmaxP: X is in K and satisfies the variational inequality <H - X - (c / n) tr(X) I, S - X> <= 0 for every S in K; trace_argmax_eq, X is the only point of K that does.
  • trace_argmax_ge: trace_quad c H S + min(1, 1 + c) |S - X|_F^2 <= trace_quad c H X for every S in K; trace_argmax_unique, X is the only maximizer of trace_quad c H on K.
  • trace_argmax_lipschitz: |X(H) - X(H')|_F <= |H - H'|_F / min(1, 1 + c).
  • trace_argmax0 and trace_argmax_norm: if 0 is in K, then X(0) = 0 and |X(H)|_F <= |H|_F / min(1, 1 + c). trace_argmax_cone: if K is a cone, then <H, X> = |X|_F^2 + (c / n) (tr X)^2 = trace_quad c H X.
  • trace_argmax_conj: if K is invariant under the conjugations S |-> Q S Q^T by the orthogonal matrices Q, then X(Q H Q^T) = Q X(H) Q^T.

Main result, as the README states it

With the same hypotheses, |X(H) - X(H')|_F <= |H - H'|_F / min(1, 1 + c). If 0 is in K, then X(0) = 0 and |X(H)|_F <= |H|_F / min(1, 1 + c). If K is a cone, then <H, X> = |X|_F^2 + (c / n) (tr X)^2 = trace_quad c H X. If K is invariant under the conjugations S |-> P S P^T by orthogonal matrices, then X(Q H Q^T) = Q X(H) Q^T for every orthogonal Q.
